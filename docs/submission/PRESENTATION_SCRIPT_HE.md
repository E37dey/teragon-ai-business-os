# תסריט מצגת (S12.1)

תסריטים מדויקים למצגת ההגשה: מעלית 60 שניות, 5 דקות, 10 דקות — עם המסכים המדויקים,
הפעולות, המעברים, ומסלול חלופי אם משהו נכשל. **אין להציג את כל 32 המסלולים.** אמרו פעם
אחת בתחילה: *"כל הנתונים סינתטיים; לקוחות ואנשי קשר מחוברים ל-Supabase עם RLS, השאר דמו
מקומי כן."*

## מעלית · 60 שניות

"TERAGON הוא מערכת הפעלה עסקית מבוססת-AI בעברית. ה-AI כאן **מציע ואדם מחליט**: שבעה
סוכנים, כל אחד עם שתי פעולות עסקיות דטרמיניסטיות — עם ראיות, הסבר 'למה', ושער אישור לפני
כל שינוי. לקוחות ואנשי קשר חיים על Supabase עם בידוד דיירים (RLS); השאר דמו מקומי כן.
אין מודל מרוחק, אין תופעות-לוואי חיצוניות, אפס גלישה ב-32 המסלולים, ונגישות מלאה. זהו
Tested MVP מוכן להגשה."

## חמש דקות (המסלול המומלץ)

1. **(0:30) התחלה מהירה / מרכז השליטה `/`** — הצביעו על 4 כרטיסי ה-KPI וכרטיס **החלטת-AI
   עם אישור אנושי** (קראו את ה-"למה" + ראיות, ואז אשר/דחה/פתח ראיות). מסר: AI מציע, אדם מחליט.
2. **(0:45) לקוחות `/customers` (LIVE)** — צרו לקוח, ערכו, הראו ולידציה. Supabase + RLS.
3. **(0:30) כרטיס לקוח `/customers/cu-1`** — תצוגת פרטים חיה.
4. **(0:30) אנשי קשר `/contacts` (LIVE)** — הוסיפו איש קשר משויך ללקוח.
5. **(0:30) סוכני AI `/agents`** — פתחו את מעבדת ה-AI; הצביעו על "מנוע חוקים מקומי — ללא
   מודל מרוחק".
6. **(0:30) Hunter** → *איתור לקוחות חסרי מידע* → ראיות + קישור ניווט.
7. **(1:00) Fixer** → *הצעת תיקון* (`dc-2`, "הצעה בלבד") → *החלת תיקון מאושר* → **ממתין
   לאישור** → **אישור והחלה** → **הוחל**; הריצו שוב → **כפילות נחסמה**.
8. **(0:15) Orchestrator** → *בניית תוכנית פעולה* (מדורגת, בעלים, יעד ניווט).
9. **(0:15) בריאות המערכת `/system-health`** — אבחון מקומי.
10. **(0:30) סיכום ארכיטקטורה ואיכות** — 0 גלישה, a11y, cross-browser, ציון 8.6/10.

## עשר דקות

1. **(1:00) `/` מרכז שליטה** — KPIs, כרטיס אישור, רשת סוכנים.
2. **(1:30) לקוחות (LIVE)** — רשימה → יצירה → פרטים → עריכה → ולידציה → שגיאה בטוחה.
3. **(1:00) אנשי קשר (LIVE)** — יצירה + קריאה משויכת ("אין מחיקה — בכוונה").
4. **(2:30) סוכנים — 3–4 סוכנים:** Hunter (שתי הפעולות), Fixer (הצעה→אישור→החלה→כפילות),
   Nexa (שאלת מערכת + הכוונה), Wiki (חיפוש + סיכום עם מקור).
5. **(1:30) ממשל `/governance` + מסגור מעבדת AI** — HITL, דטרמיניסטי, ללא מודל/צד-חיצוני.
6. **(1:00) רספונסיביות וניווט** — הקטנה למובייל: hamburger, quick-add, selects מתוקננים, מצב כהה.
7. **(1:00) הגשה `/submission` + `/submission/presentation`** — אינדקס הראיות ומצגת השקפים.
8. **(0:30) סיכום** — שערי איכות ירוקים; מגבלות מוצהרות בכנות.

## מסלול חלופי (אם רשת/נתונים נכשלים)

- **Supabase לא זמין:** הישארו ב-**מצב הדגמה מקומי** (ברירת מחדל) — לקוחות/אנשי קשר עדיין
  מדגימים את הזרימה מעל IndexedDB; אמרו בפירוש שזו הדגמה מקומית.
- **הדרוזר/דיאלוג נתקע:** רעננו — מוטציות הדמו בזיכרון מתאפסות (וזו נקודה לטובתנו: הסבירו
  שזו התנהגות דמו מתועדת).
- **מסך כבד:** דלגו לפעולת Fixer (שער האישור) — היא ה"וואו" הבטוח של ההדגמה.
- **הכול נופל:** הציגו את `docs/submission/TRUSTED_AI_TEST_PACK_HE.md` ואת ה-verdict
  הממוזג — הראיות עומדות בפני עצמן.
