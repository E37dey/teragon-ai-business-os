# EVALUATOR GUIDE — TERAGON AI BUSINESS OS

מדריך לבוחן/מעריך הקורס · Phase 9 · בעלות W9-E

מסמך זה מסביר איך לפתוח את הדמו, להריץ את מסלול ההערכה, למצוא כל אחד מ-12 התוצרים,
ולהבין את מצבי הכנות. **עיקרון-על:** כל מקום שכתוב בו "**טרם נמדד**" או "**ממתין
לאישור אנושי**" הוא כנות מתוכננת — לא פער או תקלה.

## 1. פתיחת הדמו

הדמו רץ מקומית-בדפדפן (Vite + React). מספריית הפרויקט:

```bash
npm ci
npm run dev      # פיתוח — פותח את ה-SPA
# או
npm run build && npm run preview   # תצוגת production מקומית
```

> להערכת פונקציות ה-AI צד-שרת (ai-health / ai-config) יש להריץ `netlify dev` (:8888).
> ללא זה הפונקציות מציגות "לא זמין" בכנות — ה-SPA עצמו רץ מלא בלי צורך בהן.

בעליית האפליקציה נזרעים אוטומטית נתוני הדגמה דטרמיניסטיים (`seedIfEmpty()`), כך שכל
בוחן רואה בדיוק אותה תמונה. מרכז הפיקוד נפתח עם "**ערב טוב, צחי**" (המנכ"ל צחי זוסטייהם,
טרגון טכנולוגיות).

## 2. "מצב הדגמה לבוחן" — איפוס וריצה מבוקרת

במסלול `/submission/presentation` קיים **מצב הדגמה לבוחן** (W7-F):

- **הפעלה** — מדליק דגל sessionStorage שחוסם פעולות הרסניות (יצירה/עריכה/מחיקה) כדי
  לשמור על נתוני הדגמה דטרמיניסטיים; ניווט וקריאה תמיד מותרים.
- **איפוס נתוני הדגמה** ("אפס נתוני הדגמה", עם דיאלוג אישור) — מנקה **כל** collection
  ומזרע מחדש דרך `seedIfEmpty()` הקנוני + מריץ מחדש bootstraps אידמפוטנטיים. מאפס גם
  את התקדמות 11 הצעדים ל-"לא בוצע". **הכול מקומי (IndexedDB) — עובד אופליין, אין רשת.**
- **התקדמות 11 הצעדים** נשמרת ב-collection (`demoSteps`) ⇒ שורדת רענון דף.

השתמש באיפוס לפני כל ריצת הערכה כדי להתחיל מנקודה נקייה.

## 5. הרצת המצגת (10 דקות)

`/submission/presentation` — **5 מקטעים × 120 שנ' = 600 שנ'** (`PRESENTATION_SECTION_TITLES`):

1. הבעיה והקהל
2. שבע פרסונות ומסלולי ההדרכה
3. תכנית הטמעה בשישה שלבים ו-Stage Gates
4. הדגמת Quick Start או Microlearning
5. שלוש רמות המדידה והסיכון המרכזי

כל מקטע מטמיע רכיב חי מהמסלול הרלוונטי + לינק הדגמה + תמונת גיבוי אמיתית. `actualRehearsalSeconds`
מוצג "טרם נמדד" עד שנמדדה חזרה אמיתית — מספר לא מומצא.

## 6. משמעות "טרם נמדד" ו"ממתין לאישור" — כנות בעיצוב

- **"טרם נמדד" / "לא הוגדר קו בסיס":** baseline=null בכל 22 המדדים; אין telemetry מקומי.
  מספרי יעד (ROI 3X, WAU 70%, NPS, ₪3,840) קיימים **רק** כטקסט יעד מסומן — לעולם לא כמדידה.
- **0/12 תוצרים "מלא":** "מלא" נגזר ודורש אישור אנושי בשם ממנוע האישורים. שום AI לא מסמן
  תוצר כמושלם. רוב התוצרים "ממתין לבדיקה"/"חלקי" עד שהמפעיל מאשר.
- **G4 חסום · 0 מדיניות פעילה:** אין פיילוט אמיתי שרץ; אין העמדת פנים.

**כלל הבנה:** אם המסך מראה "חסם" או "טרם נמדד" — זו התנהגות תקינה ומכוונת. מסך שהיה
מציג 12/12 ירוק ללא אישורים היה ה*ליקוי*.

## 7. הסבר Mode A

`AI_REMOTE_ENABLED=false`. כל תשובת AI מגיעה ממנוע כללים מקומי ומתויגת ככזו ("הספק
המרוחק אינו זמין. המערכת עברה למנוע המקומי מבוסס הכללים."). אין שם מודל בצד הלקוח,
אין הוצאה כספית (`maxUsageBudgetILS=0`), אין קריאת רשת ל-AI. זו החלטת אבטחה ועלות
מכוונת לדמו ציבורי — הפעלת ספק אמיתי מתוארת ב-OPERATOR_GUIDE.md (env בשרת בלבד).
