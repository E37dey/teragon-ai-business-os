## Security flags (consolidated)

1. **Browser AI calls — DO-NOT-PORT.** The frozen snapshot itself is clean: `aiCallLLM` only ever POSTs to a user-configured _server_ endpoint and lines 2307–2311 + the Settings explainer (1864–1866) document why direct provider calls are forbidden (key exposure via devtools + CORS). Older archive relatives of this file fetched `api.anthropic.com` from the browser — if any other legacy HTML is mined later, that pattern is REJECT on sight. teragon-os Wave 5 must keep keys exclusively in server functions.
2. **Unescaped HTML interpolation in print paths.** `printQuote` (592–620) and `printBrandedDoc` (621–655) inject client names/free text into `document.write` HTML with no escaping — self-XSS via crafted record fields. Rewrite with proper escaping/React rendering → print CSS.
3. **Demo auth.** Role-pick login (757–801) has no credentials; any port needs real auth before multi-user use.
4. **Synthetic PII.** Seed names/phones/emails are fake but realistic; keep them obviously synthetic (example.com etc.) in the new seed.
5. **User-configurable LLM endpoint** (Settings): if teragon-os ever relays through its own server, validate/allowlist the target (SSRF).
6. **localStorage persistence** holds all business data unencrypted — fine for demo; teragon-os uses IndexedDB with the same caveat until a backend exists (already planned).
7. `clearAllState` wipe button (1874) — keep behind confirm in any port.
