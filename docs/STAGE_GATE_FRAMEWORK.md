# STAGE GATE FRAMEWORK — שערי מעבר וראיות (Wave 7, W7-C · Phases 7.7-7.9)

בעלות: W7-C. מסך: `/stage-gates` (ראוט קיים ב-`routes.ts`; חיבור העמוד — בקשת אינטגרציה, ראו `docs/integration-requests-w7c.md`).

## עקרון-העל

**אין שער שעובר בלי ראיות אמת.** ראיה = הפניה מוקלדת (typed ref) לרשומה קנונית קיימת. אין ראיות טקסט-חופשי, אין שדה אחוז בשום מקום במודל, ואין מסלול קוד שבו אחוז התקדמות מעביר שער (נאכף בבדיקות `tests/stage-gates/canonical.test.ts`).

## גשר V2 (אידמפוטנטי)

`StageGateService.ensureBridge()` מזהה את שש רשומות ה-seed (sg-1..sg-6) ומוסיף להן שדה `v2` — **בלי להחליף אותן ובלי ליצור רשומות חדשות**. אם רשומה חסרה — הגשר נכשל ב-`STAGE_GATE_SEED_INVALID` (שומר ה"בדיוק 6"). ריצה שנייה לא משנה דבר.

ה-bootstrap מצרף אך ורק ראיות שקיימות באמת ב-seed:

- **G1**: 7 הפרסונות (per-1..per-7) → הקריטריון "מפת פרסונות" מולא; קריטריון "מטרת הפתרון" נשאר ריק ביושר — **אין** רשומת Use-Case-Brief ב-seed, ולכן G1 עולה כ-"חסרות ראיות" (ולא Go מפוברק).
- **G2**: 6 חומרי הדרכה שמכסים את כל הפרסונות בעלות מסלול + FAQ (tm-12) + נוהל תמיכה (tm-13) → "בבדיקה" (מוכן להחלטת אדם; לא הוכרז Go אוטומטית).
- **G3**: אחראית (נעה פרידמן) + נוהל תמיכה בלבד → "חסרות ראיות" (אין PilotDefinition ואין קו בסיס).
- **G4-G6**: כלום → "לא התחיל".

סטטוס legacy (`status: לא התחיל/בתהליך/עבר/נכשל`) מסונכרן רק בעקבות החלטה אנושית (Go→"עבר", No-Go→"נכשל", פתיחה מחדש→"בתהליך") — לעולם לא על ידי ה-bootstrap.

## המאמת הדטרמיניסטי (7.8)

`validateGate(gate, def, ctx, nowISO)` — פונקציה טהורה. פלט לכל שער: מצב לכל קריטריון, ראיות נדרשות/מצורפות, פסולות/פגות תוקף/חסרות, אחראי, בודק, החלטה + תאריך, מועד החלטה מתוכנן, ורשימת `blockingReasonsHe` מלאה.

### כללי כשירות ראיה

| סוג ראיה | הכלל |
|---|---|
| מאמר ידע | חייב לעבור את `mayUseAsEvidence` הקנוני (W6-C) — **טיוטה ≠ ראיה מאושרת**; פג-תוקף/בארכיון פסולים |
| חומר הדרכה | חומר שנדחה (`approvalState: "נדחה"`) פסול |
| תצפית מדד | `value: null` = "טרם נמדד" — פסולה; ישנה מ-90 יום — "פג תוקף"; קריטריון מבוסס-מדד (`needsBaseline`) בלי תצפית קו-בסיס מוקדמת עם ערך — חסום ("לא הוגדר קו בסיס") |
| כל סוג | הפניה לרשומה שאינה קיימת — פסולה; סוג שאינו נדרש לקריטריון — פסול |
| רמת שער | אחראי ללא שם חוסם ("לא הוקצה אחראי"); בודק חסר חוסם |
| **G4** | **בלי רשומת PilotResult אמיתית — G4 לעולם לא Go** (חגורה כפולה: קריטריון + בדיקה מפורשת ב-validator + סירוב ב-decideGo) |

### שבעת מצבי השער (כולם ברי-השגה — נבדק)

`לא התחיל` · `בבדיקה` · `חסרות ראיות` · `Go` · `No-Go` · `פג תוקף` · `נפתח מחדש`

גזירה דטרמיניסטית: פתיחה-מחדש ללא החלטה חדשה → "נפתח מחדש"; No-Go → "No-Go"; Go שהראיות שלו כבר לא תקפות → "פג תוקף" (Go לא נשאר ירוק בשקר); בלי החלטה: אפס פעילות → "לא התחיל", הכול מולא + אחראי + בודק → "בבדיקה", אחרת → "חסרות ראיות".

## המסך (7.9)

- **ימין**: נווט 6 השערים (מצב + ראיות תקפות/חסרות לכל שער).
