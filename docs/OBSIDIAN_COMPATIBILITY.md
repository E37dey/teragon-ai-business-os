# OBSIDIAN COMPATIBILITY — ייבוא/ייצוא זיכרון (Wave 6, W6-B)

תאריך: 23.07.2026 · בעלות: W6-B (Import/Export & Obsidian Compatibility)

## הצהרת כנות

- **אין גישה ישירה לתיקיות מקומיות.** האפליקציה רצה בדפדפן; "סנכרון כספת" אמיתי (file-watcher) אינו קיים ואינו מוצג כאילו קיים. הייבוא הוא בחירת קבצים ידנית; הייצוא הוא הורדת קובץ אמיתית (Blob). שורות הסטטוס ב-rail: **"ייבוא וייצוא Obsidian פעיל"** + **"גישה מקומית ישירה אינה פעילה"** (`obsidianStatus()`, `src/memory/export/status.ts`).
- **ייבוא לעולם אינו כותב זיכרון.** כל קובץ הופך ל-`MemoryProposal` דרך `workflow.submitProposal` — אישור אנושי בשם (מנוע האישורים הקנוני) נדרש לכל פריט. 0 אישורים אוטומטיים (נבדק).
- **ZIP ללא ספרייה.** לא נוספה תלות npm (jszip וכו'). קריאה: מימוש עצמי מעל `Uint8Array` — store (method 0) ישירות, deflate (method 8) דרך `DecompressionStream("deflate-raw")` של הפלטפורמה. כתיבה: **store בלבד** — כן ופשוט, ללא "דחיסה מדומה".

## תת-הקבוצה הנתמכת של Markdown

כותרות (H1–H6) · פסקאות · רשימות ממוספרות/לא-ממוספרות · צ'קליסטים (`- [ ]`/`- [x]`) · הדגשות (`**`, `*`, `` ` ``) · בלוקי קוד מגודרים · קישורים פנימיים/חיצוניים · טבלאות · ציטוטים (`>`) · `#tags` · `[[wikilinks]]` על 4 צורותיהם (`[[Title]]`, `[[Title|Display]]`, `[[Title#Section]]`, `[[Title#^block]]`) · YAML frontmatter.

לא נתמך (מנוטרל או נדחה): HTML גולמי (מוצג כטקסט מוחלט + דגל `sanitized`), embeds ‎`![[...]]`‎ (מוצג כטקסט), רשימות מקוננות (משוטחות), עוגני/כינויי YAML.

### כללי אבטחת רינדור (grep-proof)

- אפס `dangerouslySetInnerHTML` בכל `src/memory/**` ו-`src/modules/memory/**` — הרינדור הוא React elements בלבד.
- HTML גולמי → טקסט מוחלט + `sanitized:true` + סיבה בעברית; המקור נשמר **רק** ברשומת המקור המאובטחת (`MemorySource.excerpt`); בגוף הנשמר התגיות מנוטרלות (`‹tag›`).
- `javascript:` / `data:` (כולם, כולל תמונות) / `vbscript:` / `file:` / scheme לא מוכר → מנוטרל (טקסט אינרטי, לעולם לא `<a>`).
- קישור חיצוני (`http/https/mailto`) → `rel="noopener noreferrer"` + סמן ↗ מפורש.
- תמונות (`![]()`) **לעולם לא נטענות** — placeholder טקסטואלי (חסימת פיקסלי מעקב).

## חוזה ה-frontmatter — 14 שדות נתמכים

| שדה | סוג | התנהגות בייבוא |
|---|---|---|
| `id` | string | מטא-דאטה בלבד (מזהים נוצרים על ידי המערכת) |
| `title` | string | כותרת הפריט (עדיפות על H1/שם קובץ) |
| `aliases` | list | רזולוציית wikilinks **בתוך אצוות הייבוא** בלבד¹ |
| `tags` | list | ממוזג עם `#tags` מהגוף |
| `memory_layer` | string | `customer/business/technical/agent_learning` או התווית העברית; אחרת `business` |
| `folder` | string | תיקיית הדפדוף (ברירת מחדל: נתיב הארכיון)² |
| `owner` | string | מטא-דאטה בלבד — הבעלות נקבעת על ידי המגיש/המאשר |
| `sensitivity` | string | `ציבורי/פנימי/רגיש/מוגבל`; אחרת `פנימי` |
| `status` | string | **מטא-דאטה בלבד** — פריט מיובא תמיד מתחיל "לא נבדק"; frontmatter לא קובע אימות |
| `created` / `updated` | date | מטא-דאטה בלבד (חותמות אמת נקבעות על ידי המערכת) |
| `review_date` | date | תאריך סקירה של הטיוטה |
| `linked_entities` | list | מטא-דאטה בלבד (קישורי ישויות דורשים אימות מול המאגר) |
| `sources` | list | מטא-דאטה בלבד (מקור הייבוא האמיתי נוצר על ידי הפייפליין) |

¹ ל-`MemoryRecordV2` אין שדה aliases — כינויים לא נשמרים אחרי האישור (מגבלה מתועדת; הרחבת domain היא של W6-A/lead).
² הבריף מנה 13 שמות תחת "14 שדות"; `folder` הושלם כשדה ה-14 — מיפוי לתיקיות הקיימות, ללא שום יכולת.

**שדות לא מוכרים** נשמרים ב-`extensions` (מטא-דאטה בלבד) ו**לעולם אינם משפיעים על התנהגות** (נבדק).

**Denylist (נכשל-סגור, נבדק):** frontmatter שמנסה להגדיר הרשאות/roles, הנחיות מערכת (prompts/instructions), עקיפת/אוטומציית אישור (`approv*`, `bypass*`), סודות (credentials/password/secret/token/api_key/private_key/auth), גישה לכלים (`tool_*`, `tools`, `mcp*`), זהות ארגון (`org_id`, `tenant*`), או קוד רץ (`exec/eval/script/shell/command/run/on_*`) — **הקובץ כולו נדחה** עם שגיאה עברית טיפוסית.

**מגבלות YAML:** תת-קבוצה בטוחה בכתיבה עצמית — סקלרים, רשימות inline `[a, b]`, רשימות block `- item`. עוגנים/כינויים/merge (`&`, `*`, `<<:`) נדחים תמיד (חסימת פצצת הרחבה רקורסיבית). מבנה מקונן בשדה נתמך נדחה; בשדה לא מוכר נשמר כטקסט גולמי ב-extensions.

## הגנות ZIP (כולן עם שגיאה עברית טיפוסית, נבדקות)

path traversal ב-4 צורות (`../`, נתיב מוחלט, אות כונן, תעלולי backslash) · פצצת ZIP (יחס מוצהר לפני חילוץ + מכסת פלט תוך כדי inflate) · ארכיון-בתוך-ארכיון · התנגשות שמות (case-insensitive) · קבצי הרצה מוסתרים (exe/js/sh/ps1/svg ועוד) · רשומות symlink (מצב unix ב-external attrs) · הצפנה · UTF-8 פגום בשמות → החלפה בטוחה + דגל · אימות CRC-32 · YAML חורג · קבצים בינאריים נדחים במפורש (אין דילוג שקט); **תמונות נרשמות כהפניה לא-בת-הרצה בלבד** (ללא טעינה).

## ייצוא (Phase 6.7)

- פתק בודד `.md` · חבילת נבחרים · כספת ZIP מלאה (store).
- תוכן: גוף + frontmatter בטוח (השדות הנתמכים בלבד) + wikilinks + tags + `export_version: teragon-memory-export/1` + `record_version`.
- **מוחרג (נבדק):** רשומות ברגישות רגיש/מוגבל אלא בהרשאה מפורשת (`includeSensitive`) · דפוסי סודות ספקים (redaction בגוף) · הנחיות מערכת/מדיניות הרשאות/פנימי-ביקורת — לא מסודרים כלל בכתיבה.
- כל ייצוא ⇒ `MemoryExportJob` + `AuditEvent` עם requestedBy / כלולים / מוחרגים+סיבות / generatedAt / checksum sha-256 (`crypto.subtle`) / מצב הורדה. הורדה אמיתית ב-Blob + `URL.createObjectURL` (seam הזרקה לבדיקות).

## ידוע ומתועד

- כתיבת ZIP היא store בלבד (ללא deflate ביצוא) — בחירה מפורשת של כנות ופשטות; קריאה תומכת גם ב-deflate.
- רשומות דור-1 (legacy) מיוצאות דרך הגשר; אין להן מקורות/אישור מתועד — זה משתקף כפשוטו ב-frontmatter.
- ייבוא חוזר של קובץ שיוצא יזוהה כחשד-כפילות (slug זהה) ויוצג למאשר — אין מיזוג אוטומטי.
