## 2. בקרות מקלדת RTL — מתועדות ופועלות

המסך מכריז את המקשים, והבדיקה מאמתת שהם **קיימים בפועל** ושהחצים באמת מזיזים שקף:

| מקש | פעולה | אומת |
|---|---|---|
| `←` / רווח | קדימה (חץ שמאלה — כיוון הקריאה ב-RTL) | ✅ שינוי שקף בפועל |
| `→` | אחורה (חץ ימינה) | ✅ |
| `N` | הערות מרצה | ✅ `notes-drawer` |
| `T` | טיימר — הפעלה/השהיה | ✅ מתועד |
| `D` | קישור דמו | ✅ מתועד |
| `B` | צילומי גיבוי | ✅ `backup-view` |
| `Esc` | יציאה ממצב מצגת | ✅ חזרה ל-overview |

**סמנטיקת RTL נכונה:** `ArrowLeft` מקדם (ולא מחזיר) — כיוון הקריאה בעברית.
הבדיקה משווה את תוכן `present-mode` לפני/אחרי ומוודאת שהוא **השתנה**.
